# أداة دبلجة فيديوهات يوتيوب عبر GitHub Actions

تحمّل فيديو من يوتيوب بأي لغة، تفرّغ الكلام لنص، تترجمه للعربية، تولّد صوت
عربي مطابق للتوقيت، وتدمجه مع الفيديو — كل هذا يشتغل على سيرفرات GitHub
Actions مجانًا، وأنت بس ترسل الأمر من جوالك.

## الإعداد (مرة وحدة بس)

راجع ملف [SETUP.md](./SETUP.md) للتفاصيل الكاملة خطوة بخطوة.

## الاستخدام اليومي — واجهة ويب محلية (موصى فيها)

```bash
bash webui/start.sh
```
افتح `http://127.0.0.1:8890` من متصفح جوالك، حط رابط يوتيوب، اضغط
**دبلجة**. تقدر تضيف حتى ٥ فيديوهات دفعة وحدة ويشتغلون تباعًا. سيّب
الجهاز وارجع له بعدين — النتيجة تكون جاهزة بمجلد `~/storage/downloads`.
التقدم محفوظ على السيرفر، فتحديث الصفحة ما يفقد أي معلومة.

## الاستخدام اليومي — سطر أوامر (فيديو واحد بالمرة)

```bash
bash local-tools/dub_from_phone.sh "https://youtu.be/XXXXXXX" small
```

## خط الأنابيب (Pipeline)

1. `yt-dlp` يحمّل الفيديو محليًا بأفضل جودة (حد أقصى 1080p)
2. `ffmpeg` يفصل الصوت محليًا ويرفعه فقط (خفيف) كإصدار مؤقت
3. `faster-whisper` يفرّغ الكلام لنص على GitHub Actions مع كشف اللغة تلقائيًا
4. `deep-translator` (Google Translate) يترجم كل جملة للعربية
5. `edge-tts` يولّد صوت عربي طبيعي لكل جملة، ويضبط سرعة الكلام نفسها
   (مش تسريع الملف) لتقارب مدة الجملة الأصلية بدون تشويه طبقة الصوت
6. `ffmpeg` يدمج الصوت الجديد مع الفيديو الأصلي محليًا على الجوال

## الملفات

- `.github/workflows/dub.yml` — تعريف الـ workflow (محرك المعالجة، لم يتغيّر)
- `scripts/dub.py` — منطق الدبلجة الكامل (TTS تحديثت لـ Edge TTS)
- `requirements.txt` — مكتبات بايثون المطلوبة على GitHub Actions
- `webui/` — واجهة الويب المحلية (Flask) وقائمة الانتظار
- `local-tools/dub_from_phone.sh` — السكربت الطرفي المباشر (بديل الواجهة)
- `SETUP.md` — دليل الإعداد الكامل
